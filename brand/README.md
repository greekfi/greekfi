# Greek.fi Brand

Brand assets for Greek.fi — a fully collateralized options protocol.

## Logos

Two versions of the Spartan helmet mark, each in black, white, and neon green.

| Logo | Description | Files |
|------|-------------|-------|
| **Helmet** (primary) | Newer, cleaner mark | `logo/svg/helmet-{black,white,green}.svg` |
| **Helmet Sketch** (original) | Original hand-drawn mark | `logo/svg/helmet-sketch-{black,white,green}.svg` |

- `logo/svg/` — vector masters (scale to any size)
- `logo/png/` — transparent PNGs at 1024px and 2048px

Use **white** on dark backgrounds, **black** on light backgrounds, and **neon green** for accent/dark uses.

## Colors

From the greek.fi front page:

| Name | Hex | Usage |
|------|-----|-------|
| Black | `#000000` | Primary background, text on colored buttons |
| White | `#FFFFFF` | Headlines, text on dark backgrounds |
| Blue | `#3B82F6` | Primary actions, buttons (Tailwind `blue-500`) |
| Light Blue | `#93C5FD` | Wordmark, accents, secondary buttons (Tailwind `blue-300`) |
| Neon Green | `#00E64F` | Accent, highlight actions |

## Typography

**Martel Sans** (Google Fonts) — weights 300, 400, 600, 700. May be italicized.

```css
font-family: "Martel Sans", sans-serif;
```
